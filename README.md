## ⚡ Philosophy & Core Concept

Most habit trackers fail because they demand too much effort: checking 25 checkboxes, filling complex tables, and acting like a corporate spreadsheet.

**Daily Verdict** is built on a single, powerful principle: **Brutal Daily Accountability in 1 Second.**

Every night before bed, you give your day a simple, honest verdict from **1★ (Rough/Shit)** to **5★ (Peak/Hit)**. You write raw, unfiltered thoughts about what actually happened, and the system turns that raw data into:
- Visual habit heatmaps and weekday velocity patterns.
- High-res streetwear lockscreens and story posters.
- Unfiltered, brotherly AI forensic evaluations that roast your dopamine traps and celebrate your wins.

## 🕒 The Interactive Radial Dial Clock (How-To Guide)

The **Radial Dial Clock** is a custom-engineered time selection dial that replaces standard boring dropdown menus with a tactile, analog-inspired circular dial.

```
                  12
             11        1
          10     (●)      2
         9   ───○─────────  3   [ AM ] / [ PM ]
          8               4
              7        5
                  6
```

### How to Use the Radial Clock:

1. **Opening the Clock**: Open **⚙️ App Settings** and tap the **DIAL** button next to *Daily Streak Reminder*.
2. **Step 1 — Drag the Hour Dial**:
   - The dial starts in **Hour Mode (1 to 12)**.
   - Tap or drag the glowing neon pointer to your desired hour (e.g. `10`).
3. **Step 2 — Automatic Teleportation**:
   - The moment you release the pointer on an hour, the clock **automatically teleports you to Minute Mode** after a smooth 300ms transition.
4. **Step 3 — Pick or Fine-Tune Exact Minutes**:
   - Drag around the 60-minute circumference for continuous minute selection.
   - Use the **`[ - ]`** and **`[ + ]`** micro-steppers beside the digital minute box to dial exact times like `10:47`, `10:38`, or `09:23`.
5. **Step 4 — Select AM / PM & Confirm**:
   - Tap the **AM** or **PM** chip.
   - Tap **`[ SET REMINDER TIME ]`**. The app schedules a local browser notification that reminds you every evening so you never break your streak!

## 🤖 AI Diary Ghostwriter & Language Isolation

Writing diary reflections when you're tired can be messy. The built-in **AI Ghostwriter** takes your rapid, unstructured thoughts and polishes them into structured personal diary entries.

### How It Works:
- **1st-Person Perspective**: Writes strictly as `"I"`, `"my"`, `"myself"` — never talks down to you or uses `"You"`.
- **Zero Compression**: Preserves every single event, conversation, feeling, and detail in full narrative depth.
- **Strict Multilingual Isolation** (Configurable in **⚙️ App Settings**):
  - **`⚡ Auto-Match`**: Automatically mirrors your input language. If you write in English, it outputs 100% pure English with zero Hindi/Hinglish words.
  - **`🇬🇧 English`**: Strictly enforces fluent, polished English for all reflections and dossier reports.
  - **`🇮🇳 Hinglish`**: Generates authentic, conversational, witty Hinglish (Hindi in Roman script).

## 🛡️ Offline-First Architecture & Cloud Sync

Your data belongs entirely to you. Daily Verdict is built with a dual local-cloud architecture:

1. **Sub-1ms Local-First Mutations**:
   - Every rating, verdict change, and journal note writes immediately to local state and `localStorage`.
   - The app works 100% offline without an internet connection.
2. **4-Second Cloud Sync Race**:
   - When signed in with Google, entries sync to Firebase Firestore asynchronously.
   - If your network drops or lags, the save operation times out after 4 seconds and queues locally, preventing the UI from freezing.
3. **Privacy Calibration (Trinno Identity)**:
   - When running on `localhost:5173` or authenticated as the primary developer, personal enterprise emails are masked as `Trinno` (`trinno@cloud.sync`) to prevent PII leaks on streams and screenshots.

## 📱 Installing as a Mobile App (PWA Guide)

Daily Verdict is a Progressive Web App (PWA) that installs as a native application on Android, iOS, and PC.

### On Android (Chrome / Samsung Internet):
1. Open `https://trinno112.github.io/shit-or-hit/` in your mobile browser.
2. Tap the browser menu (three dots) or tap the **"Install App"** banner.
3. Tap **Add to Home screen**.
4. The app icon will appear on your home screen and open in full-screen standalone mode with zero browser bars!

### On iOS (Safari):
1. Open the website in Safari.
2. Tap the **Share** button at the bottom.
3. Scroll down and tap **"Add to Home Screen"**.
4. Tap **Add**.

## 🛠️ Technical Stack & Local Setup

### Core Technologies:
- **Frontend Framework**: React 18, Vite 5, Tailwind CSS.
- **Animations & Physics**: Framer Motion (spring physics), Canvas Confetti.
- **Icons & Visuals**: Lucide Icons, Material-UI Date Pickers.
- **Backend API Server**: Node.js, Express, Watch Mode (`node --watch`).
- **AI Synthesis**: Google Gemini 1.5/2.0 API (`gemini-3.5-flash-lite`).
- **Cloud Backend**: Google Firebase Auth & Firestore CDN Client.

### Running Locally:

```bash
# 1. Clone the repository
git clone https://github.com/TRINNO112/shit-or-hit.git
cd shit-or-hit

# 2. Install dependencies
npm install

# 3. Create .env file
PORT=5001
GEMINI_API_KEY=your_gemini_api_key_here

# 4. Start frontend and backend
npm run dev
```

- **Frontend App**: `http://localhost:5173`
- **Backend API**: `http://localhost:5001`
